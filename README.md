# 🌸 Cammunity by Spica

일본 대학생을 위한 종합 캠퍼스 소셜 미디어 플랫폼

## 📱 프로젝트 개요

**Cammunity by Spica**는 일본 대학생들의 캠퍼스 라이프를 위한 종합 소셜 미디어 플랫폼입니다. 모바일 우선 디자인으로 구축되었으며, 일본의 UI/UX 특성을 반영한 친근하고 직관적인 인터페이스를 제공합니다.

## ✨ 주요 특징

- 📱 **모바일 우선 반응형 디자인** (최대 너비 414px)
- 🎌 **일본어/한국어 혼합 인터페이스**
- 🎯 **6개 주요 섹션** (메인피드, 게시판, 시간표, 마켓플레이스, 지도, 마이페이지)
- 🌸 **계절별 테마** 및 일본 스타일 마스코트
- 📲 **푸시 알림** 및 오프라인 지원
- 🤳 **스와이프 제스처** 지원
- 💫 **실시간 상호작용** (좋아요, 댓글, 공유, 북마크)

## 🏗️ 앱 구조

### 1. 메인 피드 (MainFeed) 🏠
- 추천/팔로잉 탭 전환 시스템
- 게시물 피드 (이미지 슬라이더, 상호작용)
- 전역 검색 기능
- 사이드바 메뉴 (스와이프로 열기)
- 플로팅 작성 버튼

### 2. 게시판 (Board) 📋
- 8개 카테고리 (자유, 학업, 취업, 연애, 스포츠, 문화, 売買)
- 동아리/서클 관리 (팔로우/언팔로우)
- 인기 게시물 섹션
- 게시물 작성/조회

### 3. 시간표 (Timetable) 📅
- 7교시 × 5일 인터랙티브 그리드
- GPA 계산기 (자동 계산)
- 수업 상세 정보 (교수, 강의실, 학점, 평점)
- 주차별 메모 시스템
- 인기 강의 검색 및 추가

### 4. 마켓플레이스 (Marketplace) 🛒
- 8개 상품 카테고리
- 위시리스트 기능
- 상품 상세 모달 (판매자 프로필 포함)
- 검색 및 정렬 (최신순, 가격순, 인기순)
- 상태 표시 (새상품, 좋음, 보통)

### 5. 지도 (Map) 🗺️
- 인터랙티브 캠퍼스 맵
- 시설 검색 및 카테고리 필터
- 실시간 시설 이용 현황
- 예약 시스템
- 날씨 정보 및 공지사항

### 6. 마이페이지 (MyPage) 👤
- 프로필 관리 (편집 가능)
- 학업 정보 (GPA, 취득 단위)
- 활동 통계 (좋아요, 댓글 수)
- 알림 설정
- 다양한 설정 옵션

- 높은 정보 밀도
- 다채로운 색상과 요소
- 귀여운 캐릭터 및 일러스트

## 🛠️ 기술 스택

- **Frontend**: React 18, React Router DOM
- **Icons**: Lucide React
- **Styling**: CSS3 (Grid, Flexbox)
- **State Management**: React Hooks (useState, useEffect)
- **PWA**: 매니페스트 파일 포함

## 🌟 주요 컴포넌트

### 핵심 컴포넌트
- `App.js` - 메인 애플리케이션 컴포넌트
- `Navigation.js` - 하단 탭 네비게이션
- `MainFeed.js` - 메인 피드 및 게시물
- `Board.js` - 게시판 및 동아리 관리
- `Timetable.js` - 시간표 및 GPA 계산
- `Marketplace.js` - 마켓플레이스 및 상품 관리
- `Map.js` - 캠퍼스 맵 및 시설 정보
- `MyPage.js` - 사용자 프로필 및 설정

### 특수 컴포넌트
- `SeasonalTheme.js` - 계절별 테마 및 배경
- `JapaneseMascot.js` - 일본 스타일 마스코트
- `SwipeableContainer.js` - 스와이프 제스처 지원
- `PushNotifications.js` - 푸시 알림 시스템
- `OfflineSupport.js` - 오프라인 지원
